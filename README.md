# Delitter

Eine React Native App zur Anzeige und Verwaltung von Kursdaten. Dieses Projekt verwendet Expo für die Entwicklung und unterstützt sowohl mobile Geräte als auch Web.

---

## engine-io-client

- [Free Data API Dashboard](https://app.freecurrencyapi.com/dashboard)
- Anmeldung mit GitHub erforderlich

---

## rCore

### Voraussetzungen
- **Node.js**: [Node.js v22.11.0](https://nodejs.org/download/release/v22.11.0/)
- **npm**: Version 9.8.0 oder höher
- **Expo CLI**: Installieren Sie Expo lokal im Projekt.

### Schritte
1. **Expo installieren**: `npm install expo@^52.0.0`
2. **Projekt initialisieren**: `expo init Delitter -t expo-template-blank-typescript`
3. **Abhängigkeiten installieren**: `npm install`
